# Roadmap

Where this project is going, and where it is not. Replace the text in each section when you start a project from this template.

## What this is

One or two sentences: what the project is for and who it is for.

## What it is not

Scope rules, written early. A good list names things that are tempting but out of scope, and why. For example: "It plans and writes; it does not produce images, video or audio."

## Now

The step being built. Link to its design page in `docs/technical/` if there is one.

## Next

The agreed order of the next few steps. Mark finished steps with ✅ and keep them, so the history of the plan stays readable.

## Later

Ideas that are wanted but not scheduled. Moving an idea here is a decision: note it in [the decision log](docs/technical/decisions.md).
